# Tic-Tac-Toe Game

A simple **Tic-Tac-Toe game** developed as a programming project. Two players take turns placing their symbols on a 3×3 game board. The first player to get three symbols in a row wins.

## Features

* Two-player gameplay
* 3×3 game board
* Player turns
* Win detection
* Draw detection
* Score tracking
* Restart functionality
* Simple user interface

## How to Play

1. The game starts with Player 1 using **X**.
2. Player 2 uses **O**.
3. Players take turns selecting an empty position.
4. The first player to get three symbols in a row wins.
5. A row can be horizontal, vertical, or diagonal.
6. If all positions are filled without a winner, the game ends in a draw.

## Board Example

```text
     |     |
  X  |  O  |  X
_____|_____|_____
     |     |
  O  |  X  |  O
_____|_____|_____
     |     |
  X  |     |  X
     |     |
```

## Controls

Select a position on the board by entering its corresponding number.

```text
 1 | 2 | 3
---+---+---
 4 | 5 | 6
---+---+---
 7 | 8 | 9
```
